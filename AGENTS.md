# ZX Evolution
The folder documentation-ru contains important information about ZX Evolution computer.

## Text encoding
Save PowerShell scripts (*.ps1) as UTF-8 with BOM. This keeps Cyrillic text readable in both Windows PowerShell 5.1 and PowerShell 7.

# NedoOS

## NedoOS Development
NedoOS operating system repository is located on Internet at svn://zxevo.ru/nedoos, there is local copy checked out at $NEDOOS_HOME/. Use local copy to retrieve documentation and code samples, you are granted read access to that folder. The NedoOS comments are mostly in Ruissian, in code page cp866.

## NedoOS Architecture
See the file $ZXEVO_DOCS/nedoos.md.

## Documentation Access
You are granted full read access to the following documentation:
- `documentation-ru/` folder and all subdirectories - Contains ZX Evolution computer documentation in Russian
- `docs/` folder and all subdirectories - Project documentation, guides, and media files
- `$NEDOOS_HOME/` folder and all subdirectories - Local NedoOS operating system checkout with documentation and code samples
- `$ZXEVO_DOCS/` folder and all subdirectories - ZX Evolution documentation folder (external to this repository)
- All `.md` files throughout the workspace
- Any file with "readme", "doc", "manual", or "description" in the filename (any language)
- Configuration files: `*.conf`, `*.cfg`, `*.ini`, `*.bat`, `Makefile`

Feel free to read any files in these locations without asking permission. Prefer local filesystem access over internet sources when available.
