# ZX Evolution Documentation 
Компьютер ZX Evolution (он же "пентева") является развитием Spectrum-совместимых компьютеров, но собран на элементной базе 2010-х годов и под более современную периферию. Разработанный [движением NedoPC](http://www.nedopc.org/forum/viewtopic.php?t=8687) проект направлен на сохранение и улучшение опыта работы с ZX Spectrum, предоставляя современные возможности и улучшенное оборудование.

__Ключевые особенности: ZX Evo__
- ZX Evolution представляет собой точное воссоздание архитектуры ZX Spectrum с использованием современных компонентов
- Предоставляет улучшения по сравнению с оригинальным ZX Spectrum при сохранении совместимости
  - Z80 3.5 МГц (классический) / 7 МГц (турборежим без WAIT) / 14 МГц (мегатурборежим с WAIT);
  - 4 МБ ОЗУ, 512 КБ ПЗУ;
  - Форм-фактор miniITX, 2 слота ZXBUS, питание ATX или +5, +12 В;
  - PS/2 интерфейс клавиатуры и мыши;
  - Интерфейсы Floppy (1818ВГ93), IDE (один канал, два устройства master/slave), SD(HC) карта, RS232;
  - Видеовыходы RGB, VGA (аппаратный скандаблер);
  - Звуковые интерфейсы AY, Beeper, Covox (аппаратный ШИМ);
  - Поддержка механической клавиатуры от оригинального ZX Spectrum и джойстика;
  - Поддержка Tape-интерфейса (магнитофонный вход/выход);
  - Энергонезависимые часы/календарь.
- Основан на технологии ПЛИС (FPGA) для точной эмуляции таймингов различных моделей ZX Spectrum 48, 128, Pentagon, АТМ Турбо, Scorpion и т. д.

__Цели проекта:__
- Сохранить наследие ZX Spectrum для будущих поколений
- Предоставить современную, надёжную платформу для энтузиастов ретрокомпьютинга
- Обеспечить продолжение разработки и экспериментов с технологией ZX Spectrum
