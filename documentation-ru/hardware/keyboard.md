# Клавиатура ZX Evolution

## Клавиатура Spectrum

Оригинальная клавиатура имеет 40 клавиш. Одна клавиша может вводить букву, символ или слово BASIC. Результат зависит от модификаторов и режима редактора. Игры и прикладные программы определяют управление самостоятельно.

| Обозначение | Название | Стандартная PS/2-раскладка BaseConf |
| --- | --- | --- |
| CS | Caps Shift | Левый Shift |
| SS | Symbol Shift | Правый Shift; также левый Ctrl |
| CS + SS | Extended Mode | Оба Shift; также левый Alt |


### Режимы редактора BASIC 48

Режим показывает мигающая буква курсора. Это режим ввода BASIC, а не переключение аппаратной конфигурации.

| Курсор | Режим | Ввод и переключение |
| --- | --- | --- |
| K | Keywords | Команды целыми словами. Включается автоматически, когда редактор ожидает команду |
| L | Letters | Строчные буквы. Редактор переходит сюда автоматически |
| C | Capitals | Заглавные буквы. CS + 2 переключает Caps Lock между L и C |
| E | Extended | Нажать и отпустить CS + SS, затем нужную клавишу. Дополнительные функции и символы; действует на одно нажатие |
| G | Graphics | CS + 9 включает/выключает ввод графических символов |

В L-режиме CS + буква даёт заглавную букву. SS + клавиша вводит дополнительный символ или слово с клавиши. BASIC 128 и другие редакторы могут использовать иной способ ввода. [Sinclair BASIC Programming Manual, глава 1](https://worldofspectrum.org/ZXBasicManual/zxmanchap1.html).

### Частые сочетания Spectrum

| Клавиши | Действие |
| --- | --- |
| CS + 1 | EDIT: редактировать текущую строку |
| CS + 2 | CAPS LOCK |
| CS + 5 / CS + 8 | Курсор влево / вправо |
| CS + 6 / CS + 7 | Курсор вниз / вверх |
| CS + 9 | GRAPHICS |
| CS + 0 | DELETE: удалить символ перед курсором |
| CS + Space | BREAK: прервать выполнение там, где программа обрабатывает BREAK |
| Enter | Подтвердить ввод или выполнить команду |

На стандартной PS/2-раскладке BREAK — левый Shift + Space. [Sinclair BASIC Programming Manual, приложение C](https://worldofspectrum.org/ZXBasicManual/zxmanappc.html).

## ZX Evo: системные клавиши BaseConf

Источники: [руководство платы](../../docs/zxevo_user_manual.md#anchor-33) и [описание BaseConf](../../docs/zxevo_base_configuration.md#anchor-6). Эти назначения нельзя автоматически переносить на TSConf.

| Клавиши PS/2 | Действие |
| --- | --- |
| F12, кратко | Soft reset без перезагрузки FPGA-конфигурации |
| Ctrl + Alt + Del | Hard reset с перезагрузкой конфигурации |
| Scroll Lock | Перебирает режимы TV/VGA с разными таймингами; горящий индикатор означает VGA |
| Shift + Scroll Lock | В описанной версии BaseConf — TV60/VGA60 |
| Print Screen | NMI; дальнейшее действие зависит от ПЗУ |
| Num Lock | Beeper/Tape-Out; горящий индикатор соответствует Tape-Out |
| 0 удерживать при F12 | Возврат в ERS из дополнительной прошивки |

Soft reset сохраняет ОЗУ; hard reset сохранность памяти не гарантирует.

**Долгое удержание F12 описано по-разному:** руководство платы указывает отключение ATX-питания через 5 секунд, описание BaseConf — hard reset без отключения питания. Поведение нужно сверять с установленной версией. 

## Функции EVO Reset Service

Источник: [ERS v0.61.01 (FE)](<../../docs/Описание сервис-прошивки ''EVO Reset Service''.md>). Значение буквы зависит от меню и от того, удерживается ли она при сбросе.

### При удержании клавиши во время SOFT RESET / F12

| Клавиша | Действие |
| --- | --- |
| CS | Перезапуск страницы ROM BASIC 128 |
| SS | Перезапуск страницы ROM BASIC 48 |
| 0 | Возврат в ERS из дополнительной прошивки |
| H | Страница помощи |
| S | CMOS Setup |
| C | Таблица цветов; Space/Enter меняет бордюр |
| D | Демонстрация GRASS |
| Другая буквенная клавиша | Краткая помощь, кроме специально назначенных букв |
| Две и более клавиши | Проверка нажатых клавиш согласно руководству ERS |

### Главное меню

Курсорные клавиши перемещают выбор. Горячие клавиши вызывают соответствующие пункты.

| Клавиша | Действие |
| --- | --- |
| 1–4 | Выбрать дисковод |
| V / Y | Перебрать реальные / виртуальные дисководы |
| M | Режимы памяти ALL/128/48 |
| W | Частоты 3.5/7/14 MHz |
| L | Магнитофонный вход / эмуляция загрузки |
| G | Выбрать назначение RESET |
| E | Разрешить перезагрузку шрифта текстового режима из ПЗУ |
| J | Выбрать шрифт из ПЗУ |
| N | Автомонтирование TRD из IMAGE.MNT |
| K | Автозапуск off / SDBoot / INI |
| Z | Загрузчик с TR-DOS-дискеты |
| F | File browser на FAT-устройстве |
| T | Загрузка с ленты, аналог LOAD с пустым именем |
| B / D | Загрузчик с CD / HDD |
| 5 | Запустить sd_boot.$C из корня SD |
| X | Perfect Commander |
| S | Сброс в TR-DOS |
| I / U | Сброс в BASIC 48 / BASIC 128 |
| R | Меню Service |
| H | Помощь |
| 8 | Показать/скрыть курсор обнаруженной мыши |
| 9 | Показать/скрыть время и дату |

### Меню Service

| Клавиша | Действие |
| --- | --- |
| R | Сброс NeoGS |
| E | Сброс CMOS |
| K / I | Форматировать виртуальный диск на 640K / 896K |
| V / B | BASIC 48 / BASIC 128 с оригинальным непатченным ПЗУ |
| M | Редактор CMOS |
| S | Тестер PC-клавиатуры |
| D | Просмотр IDE-устройств |
| C | ATM CP/M |
| T | Загрузка IS-DOS с HDD |
| F | Обновление ROM, 512K |
| U | Обновление пользовательского ROM, 64K |
| N | Демонтировать TRD-образы |
| X | Главное меню |

Форматирование, сброс CMOS и обновление ROM изменяют соответствующие данные.

### File browser

| Клавиша | Действие |
| --- | --- |
| D | Сменить FAT-устройство |
| Enter | Выполнить действие для выбранного файла |
| V | Просмотреть содержимое SCL/TRD вместо обычного действия Enter |
| X в меню выбора TRD | Вернуться в File browser |
| CS + 1 или BREAK (CS + Space) | Главное меню |

## Клавиши TSConf / TSConfig

Ниже описана **двойная TSConf+BaseConf с SEGA-джойстиками, опубликованная WBC 12.01.2023**. TS-BIOS — ПЗУ TSConf; его setup отличается от ERS. Menu — клавиша контекстного меню, обычно между правыми Win и Ctrl.

| Клавиши | Действие в этой прошивке |
| --- | --- |
| Ctrl + Alt + F12 | Переключить TSConf/BaseConf |
| Правый Shift + F12 | Сброс в setup TS-BIOS |
| Scroll Lock | VGA/TV; индикатор горит в VGA |
| Menu + F1 | Переключить бит 0 выбора дисковода: A/C ↔ B/D |
| Menu + F2 | Beeper/Covox ↔ Tape-Out |
| Menu + F3 | Включить/выключить прослушивание Tape-In |
| Menu + F5 | Запустить обновление zxevo_fw.bin с SD |

Menu + F5 запускает прошивку: используйте только при намеренном обновлении с подготовленной SD. Наличие BaseConf в других сборках TSConf этим не подтверждается. [Описание автора](https://forum.tslabs.info/viewtopic.php?f=31&t=959).

В старых версиях документированы левый Shift + F12 (альтернативный reset), Ctrl + Alt + F11 (Pong), Menu + F4 (полярность синхронизации). В апреле 2018 года TS-Labs сообщил о планируемом удалении Menu + F4 и BaseConf из AVR-прошивки. Эти назначения сверяйте с конкретной сборкой. [Обсуждение изменений](https://forum.tslabs.info/viewtopic.php?p=16835).
