# Инструкции для документации

 Сохранять распространённые англоязычные технические обозначения, единицы измерения и сокращения в их исходном написании, если это улучшает поиск по документации и соответствует принятой терминологии.

Например:
- Не заменять обозначения размеров дискет `3.5"` и `5.25"` на варианты с десятичной запятой.
- Для единиц измерения использовать англоязычные сокращения, например `360K` и `1.2Mb`, а не локализованные варианты `360 КБ` и `1,2 МБ`.
